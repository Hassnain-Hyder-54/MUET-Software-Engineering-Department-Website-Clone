# Softwre Engineering Department at MUET

A responsive, single-page student project about the B program at Mehran University of Engineering and Technology, Jamshoro.

## Project files

- `index.html` contains the page structure and content.
- `styles.css` contains the responsive visual design.
- `script.js` powers the mobile navigation, curriculum tabs, and reveal effects.
- `assets/muet-campus.jpg` is the hero photograph.
- `assets/lucide.min.js` provides the interface icons locally.

## View locally

Open `index.html` in a browser. The site is static, so no build command or package installation is required.

- [MUET undergraduate BS programs](https://www.muet.edu.pk/admissions/undergraduate-programs/bs-programs)

- [BS Artificial Intelligence curriculum](https://sw.muet.edu.pk/bs_curriculum.php)
- [Published BS AI curriculum PDF](https://sw.muet.edu.pk/downloads/bs_curriculum.pdf)

The site is an independent learning project and is not an official MUET website. Current admissions information should always be checked directly with the university.
